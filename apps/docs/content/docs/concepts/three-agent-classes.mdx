# Agent types

Agents reach your site in different ways, and the way they arrive decides where they can be
authenticated.

| Agent type | Examples | Authenticated by |
|---|---|---|
| Signed agents | OpenAI ChatGPT agent and other Web Bot Auth signers | Server — [Web Bot Auth](/docs/auth/web-bot-auth) |
| API agents | Your own agents, partner integrations | Server — [API keys](/docs/auth/api-keys), [OAuth2](/docs/auth/oauth2), [mTLS](/docs/auth/mtls) |
| Crawlers | Googlebot, Bingbot, GPTBot, ClaudeBot, PerplexityBot | Server — [verified crawlers](/docs/auth/verified-crawlers) or Web Bot Auth |
| WebMCP & browser agents | Agents driving your UI or calling `navigator.modelContext` | Browser — [browser agents](/docs/auth/browser-agents) |

## Browser agent classes

Inside the page, the browser SDK models agents by how they interact with it. Each class comes with a different detection guarantee.

| Class | Interaction path | Detection confidence |
|---|---|---|
| `webmcp` | Structured tools through `navigator.modelContext` | Stable, exact signal when present |
| `crawler` | Fetches/renders pages; identifies itself in `navigator.userAgent` | Signature match — high but spoofable |
| `dom` | Browser automation over DOM/click/type APIs | Beta, heuristic confidence score |
| `screenshot` | Pixel-level mouse and keyboard control | Not reliably detectable client-side |

```ts
const identity = await client.detect()

if (identity?.class === 'webmcp') {
  // Structured tool client.
}

if (identity?.class === 'crawler') {
  // Known AI/search bot — identity.vendor is the bot name (e.g. 'GPTBot').
}
```

**Crawlers** (`GPTBot`, `ClaudeBot`, `PerplexityBot`, `Googlebot`, …) are matched by their User-Agent token. Because a UA is self-reported, the match is high-confidence but not proof (`confidence: 0.9`), and client-side detection only catches crawlers that execute JavaScript — for a verified answer, check crawlers on the server with [verified crawlers](/docs/auth/verified-crawlers), which sees every crawler (not just JavaScript-executing ones) and confirms the claim by reverse DNS.

**Screenshot agents** should declare themselves with `presentIdentity()` or `authenticate()` if they need more trust than anonymous browsing.
