# Monthly active agents

Agentronics plans include a number of **monthly active agents (MAA)**. It works like monthly
active users in a user-auth product, applied to agents.

## Definition

A **monthly active agent** is a unique agent identity that **authenticates successfully at
least once** in a calendar month (UTC). The identity is the verified `agent.id`:

| Method | Identity counted |
|---|---|
| Web Bot Auth | the signer, e.g. `https://chatgpt.com` |
| Agent API key | `key:<agentId>` |
| OAuth2 | `oauth2:<clientId>` |
| Verified crawler | `crawler:<name>`, e.g. `crawler:Googlebot` |
| Browser verification | the verified subject from SSO, SPIFFE, mTLS or a linked session |

An identity counts **once per month** however many requests it makes: Googlebot fetching
100,000 pages is one MAA.

## Never counted

- **Human visitors** — always free and unlimited.
- **Unverified agents** — requests that look like agents but don't authenticate.

## Limits

| Plan | Monthly active agents |
|---|---|
| Free | 1,000 |
| Pro | 10,000 |
| Business | 50,000 |
| Enterprise | Custom |

The console's **Billing** page shows this month's count against your plan and warns at 80%
and 100%. Going over never breaks your site: agents keep authenticating and the account is
asked to upgrade.
